# Jasmine-Portfolios

Personal portfolio website built with HTML, CSS, and JavaScript, hosted via GitHub Pages.

---

## Version 1.0 — Original Portfolio (February 2026)

The first version was hand-coded entirely from scratch in VS Code.

**Design & Style**
- Warm brown/tan color scheme (`rgb(182, 149, 106)`, dark browns)
- Flat, solid-color backgrounds for each section
- Dark navigation bar with a simple white underline hover effect
- Cards used a dark brown background with white text and underlined headings

**Content & Sections**
- **Home:** Name heading and typing animation only
- **About:** 2 cards — Background and Interests (brief, casual descriptions)
- **Projects:** 5 cards with plain text descriptions (no tech tags, icons, or dates)
- **Experience:** 2 cards — DVELAB Research and a "Future Internship" placeholder
- **Contacts:** Phone, Email, LinkedIn, GitHub (hover lift effect on cards only)

**Interactivity**
- Typing animation on the home page
- Hover lift effect on contact cards only
- Basic responsive layout (single-column on mobile)

---

## Version 2.0 — Upgraded Portfolio (March 2026)

The second version was enhanced with the help of Amazon Kiro AI, bringing a more polished and professional design while maintaining full understanding and creative control of the code.

**Design & Style**
- Soft pink gradient color scheme (`#fce4ec` → `#f48fb1` → `#ec407a` → `#d81b60`)
- Glassmorphism card style: translucent white backgrounds with `backdrop-filter: blur`
- Navigation bar with frosted-glass effect, pink shadow, and smooth color transitions on hover
- Section headers with a shimmer animation on hover
- Gradient text on the home page title
- Pulsing animation on the "Version 2.0" badge in the Portfolio Evolution section

**Content & Sections**
- **Home:** Added a subtitle ("Computer Science Student | Software Developer | Problem Solver"), and two CTA buttons — *View My Work* and *Get In Touch*
- **About:** Expanded from 2 to 4 cards (Background, Technical Skills, Interests, Community), each with a Font Awesome icon and more detailed, professional content
- **Projects:** Reduced to 3 focused cards, each now includes a Font Awesome icon, technology tags, a detailed description, and a date
- **Portfolio Evolution *(new section)*:** Side-by-side comparison of Version 1.0 and Version 2.0, listing key features of each, with a "Key Takeaway" insight block and a direct link to view Version 1.0
- **Experience:** Expanded from 2 placeholder cards to 6 detailed cards, each with an icon, company name, date range, and quantified accomplishments
- **Contacts:** Same 4 links, now styled with the pink/white glassmorphism theme and icon scale animation on hover

**Interactivity**
- Profile picture hover scale effect
- Hover lift + shadow + border highlight on all cards (About, Projects, Experience, Evolution)
- Gradient CTA buttons with lift and glow on hover
- Font Awesome icons used throughout all sections
- Enhanced mobile responsiveness: CTA buttons stack vertically, navigation spacing adjusts, evolution insight box reflows to single column
